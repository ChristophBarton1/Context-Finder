Context Grabber Privacy Policy

The short version

Your data never leaves your computer.

Context Grabber has no servers, no telemetry, no analytics and no accounts. Everything it captures is processed and stored locally in your browser. The only time captured data goes anywhere is when you explicitly copy a report or send it to an AI tool of your choice.

Last updated: July 1, 2026

What the extension processes — locally

To build a bug report for the page you are on, Context Grabber captures, on your device only:

  • Console output — errors, warnings, uncaught exceptions and unhandled promise rejections emitted by the page (including inside its iframes).
  • Failed network requests — URL, method, status code and, if you enabled the Pro response inspector, the first bytes of the error response body.
  • Page metadata — URL, title, viewport size, browser version and detected frameworks (e.g. React, WordPress).
  • Optional, on your action only: a screenshot of the visible tab or a region you select, and the HTML/styles of an element you click with the picker.

None of this is transmitted anywhere by the extension. It exists so that you can paste one good bug report into the AI tool you already use.

What is stored, and where

  • Report history — your last 15 generated reports, stored in the browser's local extension storage so you can re-copy them.
  • Per-tab captures — picked elements and screenshots live in session storage and are cleared when the tab navigates or the browser closes.
  • Settings and license key — your preferred export target and, if you bought Pro, your license key, stored in local extension storage.

Uninstalling the extension deletes all of it. There is nothing to delete on any server, because there is no server.

Automatic secret redaction

Before any report is copied or sent, obvious secrets — API keys, bearer tokens, JWTs, password=… parameters — are replaced with [REDACTED]. This runs always, on-device, and cannot be disabled.

When data does leave your device

Only by your explicit action:

  • Copying a report puts it on your clipboard. Where you paste it is up to you.
  • "Send to …" opens or fills the AI tool you chose (e.g. ChatGPT, Claude, Lovable, Bolt) with the report text. From that moment the data is governed by that service's privacy policy, not ours.

The extension itself never phones home. It makes no network requests of its own.

Permissions, explained

  • <all_urls> — bugs can happen on any page, so the capture script must be able to run on any page you visit. It only listens; it never alters page behavior.
  • activeTab — used for the optional screenshot of the tab you are on.
  • storage — the local report history and settings described above.
  • clipboardWrite — the one-click copy of your report.

Payments (Pro)

Pro purchases are handled by a payment provider (e.g. Lemon Squeezy). Your payment details go to them directly and never touch the extension; we only see the license key they issue. Their privacy policy applies to the purchase itself.

Children, changes, contact

The extension is a developer/creator tool and not directed at children. If this policy ever changes materially, the update will be visible in this document and in the extension's changelog before it takes effect.

Questions or concerns: open an issue at github.com/ChristophBarton1/Context-Finder.

Context Grabber runs 100% locally — privacy is the product, not a promise.
